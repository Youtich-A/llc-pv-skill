# 面向复刻的观察

先读[包内video-watch说明](../components/video-watch/OPERATIONS.md)。可执行工具为 `components/video-watch/vw.py` 和 `vwtools.py`；程序路径按当前包定位，不写旧机器绝对路径。

## 核心管道

`doctor → probe → plan → 全片grid/sheet → 关键窗口连续grid/seq → 原图read → 按需OCR/ASR → 镜头/事件证据`。

- doctor核实Python、FFmpeg/ffprobe、ImageMagick、字体；主链与vwtools分别核实。若工具不齐，先报告具体缺项与可行修复，不假装已经观看。
- probe逐帧量测与全片骨架用于定位；机器解码全帧不代表模型看过每帧。plan默认预算不能证明覆盖完整，检查未采事件。
- 密度决定能否读懂动作，分辨率决定能否看清形状。大尺寸单帧不能补回漏掉的中间动作。
- 按当前原片帧率与真实PTS对短动作加密；关注出现/消失、碰撞、表情、手势、遮挡切换、闪变和相位。纯音乐也可能高度密集。
- 图版小字不作转写依据。读字回原始分辨率裁切；时间只信manifest的文件/格位/帧/PTS映射。
- **VFR边界：** 当前video-watch部分子命令的frame字段由采样时间乘标称fps估算，并非解码PTS索引。VFR、重复帧和重定时素材必须另用ffprobe逐帧PTS建立映射，核对真实提取帧后再作帧级先后结论；manifest在这种情况下只作为采样请求索引，不能直接当真实帧号证据。
- 差分与颜色掩码只找变化候选；回原图命名物体与事件。全局低均值不能排除小区域高速变化。
- OCR/ASR作候选；画面字与唱词分别记录，不将歌词文字直接等同于发音起止。未实际核对声音时，音乐时点标为未核验。

## 产物

1. 全片镜头索引：时间、章节、主体、关键动作、参考权重、候选段界。
2. 每镜证据：图版文件、帧/PTS、裁切区域、观察结论、测量/推断/未知。
3. 姿势与素材候选：景别、朝向、表情、手势、必要部件、实例复用。
4. 声音锚点：入句、重读、鼓点、特殊音效；自动onset只是候选。
5. 未看/看不清/未听校范围，后续需要补读的窗口。

三轮自检继续使用同一工具：源片和输出用统一采样清单与时间映射，不各自缩放主体以隐藏比例误差。全片对应图版查覆盖；局部连续双排查动作；差分与原图并看查位置。颜色、压缩、字体和噪点会抬高像素差异，不能只凭差分分数判定审美。

全片建立[音乐章节表](music_sections.md)，前奏、间奏、副歌提高观察和制作优先级，未听到的章节不靠画面猜成定论。读每镜时分别列每字/部件、父级、场景与相机、风格化表面；用连续参照判断谁在动。背景要看四角、边缘和暗部，不只读歌词后方。对仍不明的风格化按[空间与风格化](space_and_style.md)向用户询问效果/图片/截图路线，保留证据和未知。

逐字/父级、残留与流体、栅格与切片、局部折射与统一镜头的辨别，按需读[时间与风格机制](11_temporal_style_and_glyphs.md)。强鱼眼参考另读[phony光学层级](12_phony_optics_recall.md)。
