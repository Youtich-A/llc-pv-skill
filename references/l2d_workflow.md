# L2D 分件、绑定与 PV 素材流程

可从主技能角色制作步骤进入，也可单独要求“使用 llc-pv-skill 的 L2D 功能”。单独调用只处理角色资产，不启动整段 PV 制作或等待无关的 AE 环境。目录、接口和最终报告按本文件约定。

## 1. 识别并征求路线选择

出现关节运动、长时间重复运动、非剪影式角色表演，或 VTuber/VUP/虚拟皮套时，评估 L2D。用户指出角色动画不对时也重新评估。简单平移、剪影切换、镜头运动不必升级成模型；先区分参考中的角色动作与相机动作。

说明 [PSD2Live](https://github.com/tsunehimatoi/psd2live) 可从分层 PSD 自动生成绑定初版，再继续修改。它是独立编辑器及工具链，不是假定已安装的 Photoshop 插件，也不能从单张扁平图无损恢复所有遮挡内容。

向用户提出一个具体建议：“这段包含……，建议用 PSD2Live 制作可复用的角色绑定。是否采用？”可同时给出保持普通分件动画的选项。**在肯定答复前，不为此路线下载安装、生成分件或制作模型。** 已明确要求 L2D/PSD2Live，或会话中已同意此路线时直接沿用授权；不重复询问。

随后一次收集缺失项，先列已有答案及推荐拆法，用户只需修改：

|问题|应提供的具体选项或建议|
|---|---|
|在哪拆|已有 Photoshop、PSD2Live 或可用图像工具；记录实际可用工具|
|怎样拆|目标动作、景别、关节、左右方向、眼睛/嘴/发束/衣袖等层级；是否补全遮挡|
|PSD 由谁准备|用户交付现成 PSD；AI 依现有分件组装；AI 重绘/补绘分件|
|保真与补绘|保留原像素优先或允许 AI 重绘；重绘变化与不可见区域不能冒充原画|
|交付用途|PV 透明序列、下次编辑预览、Cubism 或 VTube Studio；需要哪一种就验证哪一种|

必要答案未到时继续独立镜头工作，不擅自选择重绘。用户明确选择 AI 重绘后，按当前宿主图像工具流程执行，不因首轮不理想自动换成其他方法。

## 2. 获取组件与环境

肯定后复用已验证安装；缺失时从官方 GitHub 仓库或 Releases 获取适合系统的版本，记录标签/commit、资产名、许可和校验值。先核对上游说明，不固定“最新版”或杜撰下载地址。源码 clone 与可运行应用部署是两件事。工具放接收者自己的工具目录，不写进技能发行目录。

接口接入按 [PSD2Live 操作参考](../components/psd2live/OPERATIONS.md)，先发现工具与只读检查。下载成功、程序启动、MCP 可访问、导入成功、绑定成功、保存并重开分别记录。未授权时不覆盖其他工程，不更改全局配置；本流程授权的是当前模型项目。

## 3. 分件与图层契约

建立 [L2D 资产工作表](../templates/l2d_asset.md)，将资产登记进当前段 `assets.md` 和共享资产索引，镜头以资产 ID 和版本引用。

- 统一画布、透明背景、坐标、缩放和角色左右定义；不要直接照抄不同 PNG 的空白边界。分别交付独立眼白、瞳仁和上睫毛；眉、鼻、嘴分开。闭嘴模型如未做口腔，明确不能完整口型驱动。
- 按实际关节拆手臂/前臂/手、身体、服装与需要摆动的部件；没有计划驱动的区域可合层，写清限制，不能用层数冒充精度。
- 转头所需的脸皮、后发、颈部与遮挡区要有合理隐藏余量；不要保留双重轮廓或穿帮黑线。AI 分件逐项比对角色身份、画风、比例和连接处。
- Alpha 在棋盘格、灰底及目标背景上复核。全透明像素的隐藏 RGB 不表示灰色光晕；先检查实际合成，不据黑底预览反复无效重生图。图集仅可在各格无串件、足够分辨率时裁出；保留来源与布局。
- 遵循安装版本的官方图层命名/分类规则；自动分类不等于正确绑定，逐层核对角色侧别与父级。

### 脖子与衣领：必须单独验的连接点

脖子通常要从脸皮中独立，放在遮挡它的衣服/衣领后面、脸后面，根部跟随身体。不能只调整图层顺序而仍让脖子继承整颗头的 X/Y/Z 旋转。头颈上端可适度跟随或用实际可用的形变/接缝工具衔接，但根部应留在领口；记录真正实现的约束，不把“父级改为身体”称作已完成 IK。

下巴后应有足够隐藏重叠，抬头/左右转/侧倾时不出现断缝。拆掉脸皮残留的颈部小尾巴；防止它随脸旋转后从侧面伸出。衣领遮盖颈根，袖口、肩部、腰部与尾巴根也按同样方法验接缝。不要无止境拉长/加宽可见脖子去掩盖错误层级。

可用软件内拆分或原像素蒙版时保持材质、网格和贴图边界一致；拓扑拆分后若重建/替图被当前接口拒绝，不盲目继续叠修。保存工作副本，从正确的分件源文件重新导入，保留原绑定版本。补绘与图像编辑遵守宿主可用工具和用户所选路线。

## 4. 绑定、动作与验证

先保存导入前源 PSD，再导入、分类、自动生成绑定。核对每个部件的父级、绘制顺序、遮罩、参数范围；眼睛/眉毛穿透选项按参考需要设置，头发不应无依据透进五官。检查默认姿态后再做眨眼、视线、头身角度及关节动作。

验证目标范围内的左右转头、抬低头、侧倾、身体倾斜和组合姿态，包含极值与过渡。脖子、肩、袖口和装饰接缝用放大图对照；既看图层静态顺序，也看动画中的前后变化。默认姿态通过不代表所有参数组合通过。

长时间循环另看完整循环首尾、接触点、头身相位与物理稳定性；参数静帧不等于循环动画已经完成。原生渲染检查后才输出 PV 所需透明序列/视频，并登记帧率、时长、Alpha、全局音乐时间与循环相位。合成回 PV 后仍参加主流程三轮完整对照，不能用模型自测替代。

仅独立制作 L2D 时按上述资产测试验收，不为了凑 PV 三轮假称看过不存在的原片。只请求改一处接缝时做受影响姿态与引用回归，不无故重做所有模型。

## 5. 可复用交付与标准报告

```text
assets/l2d/<asset-id>/<version>/
  source/character.psd        可编辑分层源，真实层数与画布已核对
  source/parts/               独立透明 PNG（已有或本次生成时保留）
  source/layout.json          如所用工具实际支持此布局格式
  project/character.psd2live  保存并重开验证的原生工程
  preview/neutral.png
  preview/pose-contact.png
  preview/motion-preview.mp4  有制作/验证运动时才提供
  export/                    按需求实际导出的序列或运行时模型
  manifest.json              由模板填写实际相对路径和状态
  README.md                  打开方法、参数范围、依赖与限制
```

原生工程用于下次打开预览，PSD 是分件源，透明序列是 PV 素材，三者不可互相冒充；没有产生的文件不要填存在路径。`.psd2live` 扩展名以当前版本为准，若工具格式变更按实际记录。Cubism 的 `.cmo3`、运行时 `.moc3` 及 VTube Studio 包只在实际导出并验证时列为已完成。保存后重开同一工程，核对材质可读、参数和约束仍在；仅磁盘文件存在不能当作重开验证。

填写 [manifest 模板](../templates/l2d_manifest.json)，最终按以下格式简洁报告：

1. 资产 ID / 版本 / 原像素分件或 AI 重绘 / 目标动作。
2. PSD：画布、真实源图层数、左右规则；应用生成层数另列。
3. 原生工程与打开方法；源 PSD、分件、预览、实际导出文件的可点击路径。
4. 绑定：颈根父级、衣领绘制顺序、头颈重叠及其他关节约束。
5. 实测：实际检查过的参数值、过渡/循环、渲染证据、保存重开状态；未测项写未测。
6. 限制：原画差异、未拆部位、口型/极端角度/外部运行时等；不要宣称“一键完美模型”。

交付只包含用户模型资产及运行所需文件，不打包整个工具安装、Python 依赖或失败试图；它们也不回流到公开技能仓库。
