# 音乐章节识别与质量分配

全片观察时建立章节表，制作分段与音乐章节是两条轴：一个副歌可以跨多个制作段，一个制作段也可包含前奏与主歌。每个镜头引用章节ID，不能为了约20秒工作分段丢掉乐段连续性。

|标签|中文|识别线索（须结合实际声音）|质量重点|
|---|---|---|---|
|intro|前奏|开头铺垫，主题/节奏建立；有时含人声|第一印象、背景完整、主视觉入场、空间与镜头机制|
|verse|主歌|叙述展开，旋律/编配相对平稳|逐字读序、持续发展、自然衔接，仍检查全背景与入退场|
|chorus|副歌|主题旋律回归、能量/编配增强；不必然更响|单字差异、父级与相机配合、重音、复杂转场、素材质量|
|interlude|间奏|歌曲内部器乐/过渡段，常连接乐段|无歌词时的完整视觉演出、空间互动、背景、装饰与镜头变化|
|bridge / outro / unknown|桥段 / 尾声 / 未知|结构反差、收束或证据不足|按实际重要性安排；未知先保留，不强行归类|

用旋律/和声/节奏、编配、唱词结构与重复关系共同判断，音量峰值、画面切换、无人声只能作线索。ASR/onset不能替代听校；无法听取时标记“视觉结构候选，待听校”，向用户核对必要信息。

前奏、间奏、副歌设为增强质量区：更密的连续帧观察、更充分的关键机制/素材核对，三轮中逐项检查每个动作与背景系统。主歌不是省略个体动画或冻结背景的许可。预算紧张时优先减少普通零散小样、合并非阻塞微调，不能挤掉三轮或遗漏主歌镜头。

章节表记录`section_id / type / start / end_exclusive / audio_evidence / confidence / quality_priority / shots`。时间边界只取有证据的值；未听校和重建选择写明。首段仍按用户肯定门禁推进，增强区不授权提前制作后段。
