# MOTTAI式角色、素材与动画制作

## 素材路线先确定

用户选择提供素材时，根据当前段脚本逐项索要：资产ID、对应镜头、姿势/表情/朝向、景别、分件要求、透明底、所需尺寸和理由。可以先给完整缺项索引，再一次请求当前待补的一项或紧密相关一组；不要用“给几张角色图”代替具体需求。已有资产先查，避免重复索要。

用户选择生成时，先核实指定模型和当前工具的实际能力。不可用时说明并取得替代路线，不擅改模型。生成/编辑位图遵守宿主实际工具说明；本技能不自带生图模型，也不依赖必须存在的外部同名技能。

## 从脚本生成资产表

对每项资产给出“必须更新 / 可选更新 / 直接复用 / 缺失待补”，以及来源、许可、路径、镜头用途、复用范围。换角色只改变获准范围；背景、文字和道具能复用时保留，不能自动全部重绘。原片截图是否可作为最终资产须按用户要求与可用性确认；分析截图不自动变成交付素材。

角色先确定稳定身份特征，再按参考补姿势。普通全身、Q版全身、头像、半身、透视手势分别准备，不用一张全身无限放大。需要拆头身、拇指、眼睛时才拆，连续转身等超出切图能力的动作单独确定路线。

先检查整包接触表的一致性，再放大眼睛、手指、掌心方向、衣服边界和长发。检查真实RGBA、四角透明、白晕、内容包围盒、最大占屏清晰度和画布是否足够。近景需要的身体尽量补足；临时延展不能留下双重下摆、拉丝或独立黑线。

简单图标优先可编辑矢量。歌词、UI字、标题和署名在合成软件排版，不能依赖生图绘制准确文字。图形与内容分离：拳头/拇指、杯体/内部物件/杯口、窗口/用户格、心形填充/外线。

## 复杂角色动画的可选 L2D 路线

关节运动、长循环、非剪影角色表演或VTuber/VUP皮套，以及用户指出角色动画不对时，先按[L2D子流程](l2d_workflow.md)提出PSD2Live方案，取得肯定并确认拆分细则后执行。不能因“只拆必要部件”而把颈部、关节或五官捆在一起；也不能把普通相机移动误判为必须建模。此功能可独立调用，产物存为项目素材与可重开的原生模型。

## 定位与实施顺序

1. 用实际可见轮廓定位。全身看脚线与身高，半身看眼中心与眼距，互动看接触点。不同PNG空白不同，Scale百分比不能照搬。
2. 先摆完成态和读序；看脸、手、文字是否争抢焦点。新角色耳朵/长发不同，按用户允许范围调整构图。
3. 选少数决定成败的窗口做小样：换姿势定位、手势语义、头身错相、接触或关键转场。
4. 再铺当前段时序、文字、主体、背景事件、装饰和材质；不要让纹理掩盖布局和动作错误。
5. 动画分局部（眼皮/拇指）、个体（人物/道具）、组级（容器及内容）、镜头、表面（颗粒/抽帧）五层。每层明确发起者、响应者和稳定阅读中心。
6. 保存可回退版本、工程引用和实际渲染路径；已完成内容不要因局部失败全部重建。

## 节拍与动作因果

母音轨是唯一全局基准。`local = global - shot_start`；周期动作保留全局相位，负余数归一化。不要每次换镜重置节拍。

每拍按需要设计预备→冲击→回弹→余势→保持，普通拍与特殊音效分别标注。自动onset和波形峰只作候选。衰减曲线可用，但不能给所有镜头套同一正弦晃动、同一缓动或固定BPM。

头与身体可反向、不同幅度；标题独立错相。容器及内部物件先共同受冲量，内部再加小迟差。新物件落入必须是新增实例，邻物响应；不能让旧物件跳起来冒充新物落入。手指向窗口时要检查所指对象与语义。

转场按状态顺序实现，例如多人分散→收拢褪白→缩进→白场，白场不能提前盖住关键缩进。切姿势、头身分动、泡泡消散和分组冲量分别说明实现边界，不宣称已完成L2D或真实动力学。

## 执行环境

先确认当前软件、字体、插件和控制接口。AE执行读取[包内操作组件](../components/aftereffects-mcp/OPERATIONS.md)，外部同名技能只作补充；没有接口时报告真实状态。不要把旧本机脚本当万能脚本，不启动/关闭用户软件来假装修复。

模型与风格化分开验收。强烈优先评估并搭建有依据的2.5D/3D场景；有视差、绕行、遮挡换序时先验证少量近中远对象和相机，再铺全场，不能压成整张预合成。真正平面手书保留平面，说明依据。具体执行读[空间与风格化](space_and_style.md)。

每字/部件的入场、持有发展、二次启动与出场分别制作，父级变速与个体微动可以并存。背景不等于若干装饰：检查图片数量/分布、四角/贴边/画外余量、遮挡时序和密度。字体、像素风、闪电粗细、星体绽放、分散气泡及四角渐暗都按参考逐项判断，不从旧片自动复制。

正式三轮优先于普通零散自查。少量关键机制小样避免做错路线；其余微调合并成完整问题集在三轮内解决。不明风格化先带证据询问用户，它可能是特效、图片或允许截取的素材；已有授权直接沿用，未获决定时先做独立部分。

逐字/父级、残留与流体、栅格与切片、局部折射与统一镜头的辨别，按需读[时间与风格机制](11_temporal_style_and_glyphs.md)。强鱼眼参考另读[phony光学层级](12_phony_optics_recall.md)。
